## About Me
매장 · 이커머스 운영 경험을 통해 데이터 기반 의사결정과 프로세스 개선의 중요성을 체득했습니다.  
이후 Spring Boot · FastAPI 기반 웹 서비스와 AI 백엔드를 구현하며 서비스 구조와 API 설계를 경험해 왔습니다.  
현재는 기능 구현을 넘어, 안정적인 배포와 운영까지 고려하는 백엔드 개발자로 성장하고 있습니다.

<br/>
